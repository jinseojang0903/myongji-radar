# 추가 수집 출처 상세 파싱 검증 결과

검증일: 2026-11-02

추가 출처 5곳을 우선순위대로 등록하고, 각 발견 목록의 앞 5건을 상세 수집했다. 기존 두 출처까지 총 7곳에서 35개 게시글을 저장했다. 같은 범위 재실행 결과 신규 0건, 변경 0건, 변경 없음 35건, 오류 0건이었다. 오프라인 회귀 테스트는 8개 모두 통과했다.

## 결론

추가한 25건 모두 상세 파싱에 성공했고, 저장 HTML과 제목·본문 텍스트·이미지 URL·첨부 URL의 구조적 일치 검사 100개가 통과했다. 이 항목에서는 5곳이 공동으로 같으므로 단독으로 정확도가 가장 높은 출처를 정할 수 없다.

현재 OCR 없는 운영에서 가장 안정적으로 활용할 출처는 **공학교육혁신센터**를 권장한다. RSS 별도 보정 없이 수집됐고, 표본 5건 모두 본문 텍스트가 있으며 첨부 10개 링크를 확보했다. **창업교육센터**도 5건 모두 본문 텍스트가 있고 실제 대회·모집 연장 공지가 있어 명지레이더의 첫 시연 대상으로 적합하다. 이는 표본과 운영 편의에 근거한 판단이며 전체 사이트의 정확도 순위가 아니다.

## 발견한 문제와 수정

- 창업교육센터: RSS 제목의 미이스케이프 `&` 때문에 XML 파서가 실패했다. 출처 설정에서 제한적인 보정을 활성화했다. 정상 엔티티·CDATA는 유지하며, 다른 XML 오류는 실패로 남긴다.
- ABI-X: 동일한 RSS 오류를 보정했다. 5건 중 4건은 원래 HTML 본문에 텍스트가 없고 이미지 한 장만 있었다. 이미지 URL은 확보했다.
- 대학혁신지원사업: RSS 주소는 XML을 반환하지만 내용은 RSS 미지원 안내와 빈 링크다. 공개 HTML 목록 첫 페이지에서 글을 발견하도록 전환했다. 현재 한 페이지 10건을 발견하며 과거 페이지 순회는 구현하지 않았다.
- 공학교육혁신센터: 표본 5건에서 별도 파서 보정 없이 제목·본문·첨부를 확보했다.
- 반도체·ICT대학: 5건 중 2건은 이미지 전용 본문이었다. 이미지와 첨부 링크는 원문과 일치했다.

## 확인 방법과 한계

`scripts/audit_samples.py`는 DB에서 출처별 최신 저장 버전을 최대 5건 선택해 저장 HTML과 비교한다. 이번에는 출처별 5건만 수집했으므로 추가 출처의 실제 수집 표본 전체를 검사했다.

1. HTML 제목과 저장 제목을 공백 제거 후 비교한다.
2. HTML 본문 영역과 저장 텍스트를 공백 제거 후 비교한다. 스크립트·스타일은 제외한다.
3. 본문 이미지 URL 목록과 저장 목록의 순서·개수·주소를 비교한다.
4. 페이지 전체의 다운로드 링크 목록과 저장 첨부 URL 목록의 순서·개수·주소를 비교한다.

이는 같은 원문 DOM을 기준으로 한 **구조적 검사**이므로, 독립 정답표로 측정한 정보 추출 정확도가 아니다. 이미지 파일 접근 성공 여부, 이미지 속 날짜·자격, 첨부의 내용, 전체 게시판 누락률, 작성일 정확도는 이번 검사에 포함하지 않는다. 표본은 RSS 순서 또는 HTML 첫 페이지 기준이며 무작위로 선정하지 않았다.

파싱 결과의 본문 시작·끝, 대회 일정 문구, 이미지·첨부 링크와 공지 유형도 확인했다. 창업교육센터의 최초 공지와 연장 공지는 서로 다른 글로 보존했고, 같은 행사로 병합하거나 마감일을 자동 추출하지 않았다. 표본별 원문 URL, 원문 HTML 경로, 글자 수와 각 검사 결과는 `data/audit/structural_report.json`에 기록했다.

## 실행 방법

BAT 실행기 1번은 이제 7곳에서 각각 최대 3건, 2번은 각각 최대 10건을 수집한다. 추가 출처 5곳이 먼저 실행되고 일반공지·교수학습센터가 이어진다.

```powershell
.\.venv\Scripts\python.exe -m collector run --limit 5
.\.venv\Scripts\python.exe -m collector run --source mju_startup --limit 5
.\.venv\Scripts\python.exe -m collector run --source mju_ecc --limit 5
.\.venv\Scripts\python.exe scripts/audit_samples.py
.\launcher.bat test
```

자동 검사 상세 기록은 `data/audit/structural_report.json`, 최초 실패 원본 RSS는 `data/audit/*.xml`, 상세 HTML은 `data/raw/`에 있다. 실패와 재실행 이력은 DB의 runs 테이블에 기록된다. 로컬 원문 데이터는 그대로 공개 배포하지 않는다.
