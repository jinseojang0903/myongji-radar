# 수집 출처 추가 대상

중복 설정이었던 루트 `collector/boards.yaml`에서 아직 등록하지 않은 4곳의 조사 정보를 옮겼다. 실행 가능한 출처 설정은 `pipeline/config/sources.toml` 하나이며, 이 문서는 미등록 대상의 조사 기록이다. 실제 등록은 [이슈 #6](https://github.com/jinseojang0903/myongji-radar/issues/6)에서 진행한다.

| 기존 ID | 대상 | 기존에 기록된 호스트·게시판 경로 | 남은 확인 |
| --- | --- | --- | --- |
| mju-student | 메인 학생활동공지 | `https://www.mju.ac.kr/bbs/mjukr/853` | RSS 지원·상세 파싱·이미지 전용 공지 확인 |
| mju-career | 메인 진로/취업/창업공지 | `https://www.mju.ac.kr/bbs/mjukr/146` | RSS 지원·상세 파싱 확인 |
| ince | 정보통신공학전공 학부 공지 | `https://ince.mju.ac.kr`, 게시판 경로 미확인 | 실제 공개 목록과 발견 방식 확인 |
| energy | 에너지 소재 사업단 공지 | `https://www.mju.ac.kr/bbs/energymaterials/1634` | RSS 지원·상세 파싱 확인 |

위 경로는 기존 조사 정보를 보존한 것으로, 이번 폴더 정리에서 네 곳의 실수집을 검증했다는 뜻은 아니다. 새 출처 등록 시 현재 수집기 ID와 데이터 계약의 공개 게시판 ID 매핑도 확인한다. 기존 7곳의 수집기 ID는 DB 호환성을 위해 이번 작업에서 변경하지 않는다 (#13에서 매핑 정리).

학생활동공지는 이미지 전용 글이 많다는 기존 조사 기록이 있다. 링크 수집과 이미지 내려받기는 구분하며, 다운로드는 #12에서 구현한다. 메인 게시판 간 같은 행사 공지는 각 출처를 보존하고 #16의 행사 병합 대상으로 연결한다.
