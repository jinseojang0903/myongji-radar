# site

정적 웹사이트. Vercel이 이 폴더만 배포한다 (아래 "배포"). 실행 중 AI를 호출하지 않는다. 외부 글꼴·라이브러리 없이 동작한다 (행사장 인터넷 없이도 로컬에서 열림).

## 배포

- 주소: **https://myongji-radar-site.vercel.app/** (Vercel 프로젝트 `myongji-radar-site`, 팀 jinseo's projects, #45)
- 설정: Root Directory `site`, Framework Preset Other, 빌드 명령 없음. `site/` 밖의 파일(pipeline·eval·docs)은 공개되지 않는다 (2026-11-06 확인: `pipeline/README.md`·`docs/api-contract.md` 등 404).
- `main`에 커밋이 들어오면 자동 배포된다. **단 커밋 작성자가 Vercel 팀 멤버일 때만**: 무료(Hobby) 팀 + 비공개 저장소라 멤버를 추가할 수 없어, 팀원이 작성한 커밋(스쿼시 머지도 PR 작성자가 작성자로 남음)은 배포가 "Blocked"된다. 그 뒤 장진서가 작성한 커밋이 `main`에 들어가면 그때의 `main` 전체가 배포된다. PR 미리보기도 같은 이유로 팀원 PR에서는 만들어지지 않는다 (PR에 Vercel 검사 "실패"로 뜨지만 머지는 막지 않는다). 누가 머지해도 배포되게 하는 방법은 #19에서 정한다.
- `data/cards.json`이 아직 없어(404) 예시 데이터를 보여 주고 상단에 예시 안내가 뜬다.

## 로컬에서 보기

브라우저 보안 때문에 `index.html`을 파일로 직접 열면 데이터를 읽지 못한다. 이 폴더에서 로컬 서버를 띄운다.

```
cd site
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 연다.

## 지키는 것

- **공지에서 온 문자열은 HTML로 해석하지 않는다.** 요소는 `el()`로 만들고 글자는 `textContent`로만 넣는다. `innerHTML`을 쓰지 않는다.
- **외부 링크는 https이고 허용 도메인(`mju.ac.kr`과 하위 도메인, `forms.gle`, `docs.google.com`)일 때만** 링크로 만든다. 아니면 글자만 보여 준다. `el('a', { href })`는 사이트 안 링크만 받는다.
- 페이지마다 Content-Security-Policy로 같은 출처의 스크립트·스타일만 허용한다 (인라인 스크립트·스타일 금지).
- 예시 데이터일 때는 기준일을 오늘 대신 예시의 `generated_at`으로 쓴다 (계약 1절).
- 실제 데이터가 36시간보다 오래됐으면 맨 위 띠에 "대회 정보가 N일 전 기준" 경고를 띄운다 (매일 갱신이 멈춰도 학생이 원문을 다시 확인하게, 계약 1절).

## 접근성·휴대폰 점검 (#27)

2026-11-05, 코드로 확인한 것 (실기기 확인·시연 리허설은 사람이 한다):

| 확인 | 결과 |
|---|---|
| 가로 넘침 (Chrome 헤드리스, 폭 320·360·540·600·768·900·1100px, 예시 데이터) | 처음엔 제작 기록(정확도 표)과 카드 상세(320px, 긴 버튼)가 화면보다 넓었다. 격자 칸이 줄어들 수 있게 하고, 표는 감싼 영역 안에서만 가로로 밀고, 좁은 화면에서 긴 버튼 글자는 줄을 바꾸게 고친 뒤 네 화면 모두 화면 넘침 0, 패널 밖으로 나간 요소 0 |
| 글자 대비 | 신청 가능·검수 완료 배지(초록)가 4.39:1이라 `--ok`를 진하게 해 4.86:1. 쓰는 조합 모두 4.5:1 이상 (`tests/a11y.test.js`가 계속 확인) |
| 입력창 경계 | 맞춤 추천 입력창 테두리가 흰 배경과 1.8:1이라 `--input-line`(3.6:1)으로 |
| 키보드 | 조작은 모두 버튼·링크다. 가로로 밀리는 표(제작 기록)는 포커스할 것이 없어 이름 붙은 영역(`role="region"`, `tabindex="0"`)으로 감싸 키보드 화살표로 민다. 남색 머리글 안의 파란 포커스 테두리는 3:1에 못 미쳐 흰색으로 |
| 색만으로 구분 | 판정·검수 상태 배지는 글자와 기호를 함께 쓴다 (예: "✓ 검수 완료", "확인 전") |
| 인터넷 없이 | 외부 글꼴·라이브러리·CDN 없음. 위 "로컬에서 보기"의 로컬 서버로 열린다 (파일로 직접 열면 데이터를 못 읽음). 제작 기록의 GitHub 링크만 인터넷이 필요하다 |

측정 방법: `site/`를 임시 폴더에 복사하고, 복사본에서만 다른 페이지 안에서 열리면 멈추는 검사(`js/page.js`·`js/log-page.js`의 `window.top` 비교)를 끈다. 그 복사본에 정한 폭의 iframe으로 네 화면을 열어 `scrollWidth`와 각 요소의 오른쪽 끝을 재는 측정 페이지를 두고, Chrome 헤드리스(`--dump-dom`)로 연다. 예시 데이터로만 쟀으므로 실제 데이터(긴 제목·긴 주소)가 들어오면 다시 잰다.

남은 것 (사람): 휴대폰 실기기(안드로이드·아이폰 Safari)로 네 화면 보기, 키보드만으로 시연 동선(홈 → 맞춤 추천 → 카드 상세 → 캘린더 받기) 해 보기, 화면 읽기 프로그램으로 판정 결과와 표가 읽히는지, 윤민기 시연 리허설.
