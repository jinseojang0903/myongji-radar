# 명지레이더

흩어진 명지대학교 교내 공지에서 **대회·공모전**을 모아, 생성형 AI가 대회 카드로 정리하는 서비스입니다. 카드의 항목마다 원문 근거 문장을 붙이고, 학생이 쓴 문장이나 고른 조건(캠퍼스·학년·학적·참가 형태 등)으로 신청 가능 여부를 판정합니다.

- **사이트:** https://myongji-radar-site.vercel.app
- 2026학년도 명지대학교 AI 리터러시 경진대회 출품작 (제출 2026-11-19, 결선 2026-11-26)

## 화면

| 화면 | 하는 일 |
|---|---|
| **홈** | 신청 중인 대회 목록. 마감 가까운 순·새 글 순, 마감 7일 이내·마감 변경·제출물·캠퍼스 필터 |
| **맞춤 추천** | "자연캠 2학년인데 혼자 낼 수 있는 대회 있어?" 같은 문장을 조건으로 바꾸고, 대회마다 신청 가능 / 팀 구성 시 가능 / 확인 필요 / 불가와 그 이유를 보여 준다. 이해하지 못한 표현은 숨기지 않고 보여 주고, 제목 검색으로 이어 준다 |
| **카드 상세** | 항목별 값과 원문 근거, 정보 충돌, 마감 변경 이력, 캘린더 파일, 담당 부서 문의 초안 |
| **제작 기록** | 처리 단계별 담당(코드·규칙·AI·사람), 정확도, 프롬프트 버전과 바꾼 이유, AI가 틀린 사례, 1분 AI 검수 체험 |

## 동작 흐름

```
[매일, 운영 PC]
학교 공개 게시판 11곳 수집 → 규칙 분석(대회 후보 고르기) → AI 추출(카드 항목 + 근거 문장)
  → 근거 대조(인용이 원문에 실제로 있는지) → cards.json 내보내기(안전 검사·수동 차단 목록) → main에 올림 → Vercel 배포

[학생 브라우저]
문장 → 표현 사전으로 조건 해석 → 규칙 코드로 판정 (AI를 부르지 않는다)
```

- **AI는 정리만, 판정은 규칙 코드가 한다.** AI가 뽑은 값은 근거 문장과 함께 보이고, 확실하지 않으면 "신청 가능" 대신 "확인 필요"로 보인다.
- 근거 문장을 원문에서 찾지 못한 항목은 근거를 공개하지 않고 "원문 확인 필요"로 내린다. 근거 대조를 거치지 않은 카드는 공개되지 않는다.
- 학생이 쓴 문장과 고른 조건은 서버로 보내지 않는다. 조건만 그 기기의 브라우저에 저장한다.

## AI를 어디에 어떻게 썼나

| 어디 | 어떻게 | 믿을 수 있게 한 장치 |
|---|---|---|
| 공지 → 카드 정리 | Claude Code 헤드리스 실행(`claude -p`). 도구와 외부 연결을 모두 끈 빈 폴더에서 부르고, 출력 형식(JSON 스키마)을 강제한다. 프롬프트는 [`prompts/`](prompts/), 바꾼 이유는 [`prompts/CHANGELOG.md`](prompts/CHANGELOG.md) | 항목마다 근거 문장을 요구하고, 근거가 원문에 실제로 있는지 코드로 대조한다. 공지 속 지시문은 따르지 말라고 지시하고, 그런 문구가 보이면 자동 검증 결과를 쓰지 않는다 |
| 추출 모델 고르기 | 사람이 원문으로 만든 정답표(대회 17건)로 Haiku·Sonnet·Opus를 비교한다 ([#9](https://github.com/jinseojang0903/myongji-radar/issues/9)) | 뜻이 같으면 정답인 항목(대회명·혜택 등)은 사람이 판정한다 |
| 개발 | Claude Code로 구현하고, 코드 리뷰·보안 리뷰 에이전트와 팀원 리뷰를 거쳐 머지한다 ([작업 규칙](CONTRIBUTING.md)) | 리뷰가 잡은 AI의 실수는 제작 기록 화면의 "AI가 틀린 사례"에 남긴다 |

학생이 쓰는 화면(조건 해석·판정·캘린더)은 실행 중에 AI를 부르지 않는다. 같은 입력에 늘 같은 답을 내고, 판정 이유를 설명할 수 있게 하려는 것이다.

## 측정 결과

측정한 것만 쓴다. 측정 파일은 저장소에 있다.

| 무엇 | 결과 | 근거 |
|---|---|---|
| 자연어 해석기 (해석기를 보지 않은 사람이 쓴 문장 50개 × 조건 7칸) | 첫 측정 **319/350칸**, 판정에 쓰는 조건을 틀린 값으로 읽은 것 7/250칸 | [`eval/parser/`](eval/parser/) |

| 판정 규칙 (무작위로 만든 카드·조건 50,000건) | 확실하지 않은데 "신청 가능"을 낸 경우 0건 (시험용 무작위 데이터라 실제 공지의 정확도는 아니다) | [`tests/rules.test.js`](tests/rules.test.js) |
| AI 카드 추출 정확도 (모델별) | 측정 중. 사람 판정을 마친 뒤 채운다 | [`eval/extraction/`](eval/extraction/) |

## 아직 못 한 것

- AI에 공지 **본문만** 넣는다. 포스터 이미지와 첨부 파일은 아직 넣지 않아서, 포스터에만 있는 정보는 놓친다.
- 다른 모델로 한 번 더 뽑아 비교하는 교차 검증은 아직이다. 그래서 근거 대조를 통과해도 신청기간·자격은 팀이 원문과 대조하기 전까지 화면에 "확인 전"으로 보인다.
- 수집은 각 게시판의 최근 목록만 본다. 그 밖의 과거 공지는 찾지 않는다.

## 폴더 구조

```
site/        정적 웹사이트 (Vercel이 이 폴더만 배포). 해석·판정·캘린더는 브라우저에서 처리
pipeline/    매일 공개 파이프라인 (Python)
  collector/   공개 게시판 수집·규칙 분석
  extractor/   AI 추출 (claude -p, 매일 추출·모델 비교)
  verifier/    근거 대조와 검증 표시
  exporter/    cards.json 내보내기 (안전 검사·수동 차단 목록)
  publisher/   위 단계를 차례로 돌리고 cards.json만 main에 올림
  merger/      같은 대회 공지 병합 미리보기 (공개 경로와 분리)
  config/      출처(sources.toml)·규칙(rules.toml)·차단 목록
prompts/     추출 프롬프트 버전별 원문과 바꾼 이유
eval/        정답표(answer_key)와 정확도 측정(extraction: AI 추출, parser: 자연어 해석기)
tests/       사이트 쪽 시험 (판정 규칙·해석기·화면 계산)
docs/        데이터 계약(api-contract.md), 화면 설계, 수집기 기록
```

## 원칙

- **로그인 없는 공개 게시판만** 수집한다.
- 공지 **원문과 첨부는 저장소에 올리지 않는다** (`data/`, AI 원본 출력은 커밋 제외). 사이트에는 요약, 짧은 근거 문장, 원문 링크만 싣는다.
- AI는 공지를 정리하고, 신청 가능 여부는 **규칙 코드**가 판정한다. 확실하지 않으면 "확인 필요"로 표시한다.
- API 키와 로그인 정보는 저장소에 두지 않는다 (`.env`는 커밋 제외, 예시는 `.env.example`).

## 실행 방법

**사이트 시험** (Node.js, 저장소 루트):

```powershell
npm test                 # 판정 규칙·해석기·화면 계산 시험
npm run eval:parser      # 자연어 해석기 정확도 측정 (eval/parser/)
```

사이트는 빌드 없이 정적 서버로 연다 (`cd site` → `python -m http.server 8000` → http://localhost:8000, [site/README.md](site/README.md)). 파일을 직접 열면 브라우저 보안 때문에 데이터를 읽지 못한다.

**파이프라인** (Python 3.11 이상, Windows PowerShell):

```powershell
cd pipeline
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\launcher.bat test      # 시험
.\launcher.bat run       # 공개 게시판 수집
```

AI 추출과 매일 공개(`python -m publisher --model <모델> --push`)는 실행하는 사람의 Claude Code 로그인이 필요하다. 단계별 설명은 [pipeline/README.md](pipeline/README.md), 데이터 형식은 [데이터 계약](docs/api-contract.md)을 따른다.
